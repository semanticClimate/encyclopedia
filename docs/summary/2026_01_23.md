## Version Management

**Current Version:** `0.0.2`

**Version Format:**
- Regular: `major.minor.point` (e.g., `0.0.1`, `0.0.10`)
- Alpha: `major.minor.apoint` (e.g., `0.0.a1`, `0.0.a10`)

**Process:**
1. Run `python scripts/bump_version.py` before committing
2. Commit with version in message: `git commit -m "Description (v0.0.X)"`
3. Version automatically incremented in `encyclopedia/__init__.py`
